Pitwall Live: go-live guide

Pitwall Live runs on your Raspberry Pi with no sample data and goes public at https://app.stingrayproductions.com through a Cloudflare Tunnel. Staff and each customer’s fleet manager get their own login from the Team page.

This trial vs. your Pi

This site is the same Pitwall Live app, running inside your browser so you can try it today. It starts empty, connects to your real MyGeotab databases, and has every login type and the same company walls.

  • Saved only in this browser. Logins you create here work only on this computer: sign out and sign in as them to see their view. On the Pi, everyone signs in from their own phone or computer.
  • Syncs while it’s open. The trial syncs MyGeotab every 15 minutes while a Pitwall tab is open. The Pi syncs around the clock.
  • MyGeotab passwords aren’t saved. The trial keeps only MyGeotab’s session key. When it expires, remove the database and add it again.
  • Erase everything in the top bar wipes all trial data from this browser.

Open the trial

Step 1: Build and flash the SD card

The card is ready once it holds Raspberry Pi OS plus the Pitwall Live kit (pitwall-live-sd-kit.zip).

  1. In your browser, download Raspberry Pi OS Lite (64-bit) from https://downloads.raspberrypi.com/raspios_lite_arm64_latest into Downloads.
  2. Save pitwall-live-sd-kit.zip into Downloads/pitwall-build, next to build_image.py.
  3. Ask Claude to build the image, or run it yourself in Terminal:
    python3 ~/Downloads/pitwall-build/build_image.py ~/Downloads/<the raspios file>.img.xz ~/Downloads/pitwall-build/pitwall-live-sd-kit.zip ~/Downloads/pitwall-live.img
  4. Write pitwall-live.img with Raspberry Pi Imager (Choose OS → Use custom). When Imager offers OS customisation, choose No: the kit already sets everything.
  5. Optional: if you already have your Cloudflare tunnel token (Step 3), save it as cloudflare-token.txt in the pitwall folder on the card’s bootfs drive.

Step 2: First start and your admin account

The admin account can only be created from the shop network, so nobody on the internet can claim it first.

  1. Plug the Pi into Ethernet and power it on. The first boot installs Pitwall (5–10 minutes).
  2. On a computer at the shop, open http://pitwall.local and create your admin account.
  3. You land on the Get ready checklist, which walks you through Step 4.

Step 3: Publish at app.stingrayproductions.com

A Cloudflare Tunnel lets customers reach the Pi over https without opening anything on your router. Your domain’s DNS moves from WordPress.com to Cloudflare first; the domain stays registered at WordPress.com.

  1. Create a free Cloudflare account and choose Add a domain → stingrayproductions.com → Free plan.
  2. Check the DNS records Cloudflare copied in. Keep the ones for your website and email, and make sure addins is a CNAME to djbasssummer.github.io set to DNS only (grey cloud), so the add-in and both demos keep working.
  3. Switch to the two Cloudflare nameservers at WordPress.com (Domains → stingrayproductions.com → Name servers). Claude can do this through the WordPress.com connection once you confirm. Allow a few hours.
  4. In Cloudflare Zero Trust → Networks → Tunnels, create a tunnel named pitwall (Cloudflared). Pick Debian and arm64, then copy the token that starts with eyJ.
  5. Add a public hostname: subdomain app, domain stingrayproductions.com, service HTTP, URL localhost:80.
  6. Save the token as cloudflare-token.txt in the card’s pitwall folder and restart the Pi. It installs cloudflared, connects, and deletes the token file.
  7. Open https://app.stingrayproductions.com on your phone over cellular to confirm.

The token is a password for your tunnel. Don’t paste it into chats or email. If it leaks, delete the tunnel in Cloudflare and make a new one.

Step 4: Onboard staff and customers

Every login is made by an admin on the Team page, and each comes with a ready-to-send message.

  1. Connect each customer. Data → Add a MyGeotab database: the database name, the customer’s name, and a MyGeotab user made just for Pitwall (view-only is enough).
  2. Add your staff. Team → Add someone → Staff, Editor or Admin.
  3. Add each customer’s fleet manager. Team → Add someone → Fleet manager, then pick their company.
  4. Send the login. Click Copy message and text or email it. Use the https://app.stingrayproductions.com/login link once Step 3 is done.
  5. First sign-in. Each person picks their own password before they see anything else.

Forgot a password? An admin clicks Reset password: it signs that person out and makes a temporary password with its own message. Roles change from the Role menu and take effect at the next sign-in.

Before you invite customers

  • Admin account created at http://pitwall.local
  • At least one MyGeotab database connected and its devices showing in Device health
  • https://app.stingrayproductions.com opens from a phone on cellular
  • A test fleet-manager login for your own database: sign in on your phone, set a password, check you see only that company
  • One staff member signed in and answered a test help request
  • Staff know the reseller demo (/demo) and this trial (/live-demo) are separate from the live site
  • Backups checked: Data → Backups shows today’s copy (the Pi keeps 30 daily and 12 monthly)
