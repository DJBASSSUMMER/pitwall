# Pitwall add-in

Hosted files for the Pitwall device-health add-in for MyGeotab. MyGeotab loads `pitwall/pitwall.html` from this site, so every database that has the add-in picks up changes as soon as this repo is updated.

Install in a database: Administration → System → System Settings → Add-Ins → New Add-In → paste `config.json` → Save.
